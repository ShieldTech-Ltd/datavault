# Light dashboard artwork

Visual source: the user-selected `DataVault Light Dashboard Interface.png`.

The globe banner, translucent ribbon/cube sidebar decoration and transparent cube brand mark were generated individually with built-in ImageGen using that screenshot as the visual reference. Files are original generated raster assets matching its palette and composition. They are not a flattened dashboard screenshot or sample business activity.

Hero and sidebar image text belongs to the decorative illustration. All navigation, metric values, forms, collection data, answer text and receipts are real HTML backed by the app's state and Worker endpoints.
