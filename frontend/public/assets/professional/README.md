# DataVault collection artwork

Eleven original images generated for this frontend with built-in ImageGen: ten category covers and a dashboard hero. Each cover started at 1536 by 1024; the hero started at 1254 by 1254. Final WebP covers are 1200 by 800 and the hero is 1200 square. All eleven served assets total 788,536 bytes.

Art direction: precision studio-rendered translucent glass sculptures, midnight navy backgrounds, electric violet and cyan lighting, no text or baked-in interfaces. The hero uses a pale background for the light dashboard. This artwork identifies preview collection categories; it does not represent private uploaded documents, actual assets under management, or real wallet identities.

Generated source PNGs remain in the local `output/artwork-originals` directory, with originals also retained in the tool's generated-image folder. The frontend references only the optimized WebP files. The earlier reference-sheet crops are retained for provenance and are no longer used by frontend components.
